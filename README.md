## 🔧 Troubleshooting

### Common Issues and Solutions

**Problem:** Download doesn't start
**Solution:** Ensure your internet connection is active and check if any firewall or antivirus is blocking IDA

**Problem:** Slow download speeds
**Solution:** Reset the connection in IDA or limit the number of simultaneous downloads

**Problem:** Browser integration not working
**Solution:** Re-enable the extension in your browser settings or restart both IDA and your browser

**Problem:** Installation fails
**Solution:** Temporarily disable antivirus software and run the installer as administrator
